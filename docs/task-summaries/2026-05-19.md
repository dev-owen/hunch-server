- `Makefile`: `build` 타겟과 `test-ci` 타겟을 추가했다. `build`는 clean checkout에서도 동작하도록 `bin/`을 생성한 뒤 `bin/hunch-server`에 API 바이너리를 빌드한다. `test-ci`는 `RUN_INTEGRATION_TESTS=1 go test ./...`를 실행한다.

- `README.md`: CI badge와 개발 명령 목록을 갱신하고, GitHub Actions가 `make build`와 `make test-ci`를 실행한다는 설명을 추가했다.
